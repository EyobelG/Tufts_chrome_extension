# Tufts Jumbos Chrome Theme

Chrome browser theme for Tufts University, styled after the [Stanford Cardinal theme](https://chromewebstore.google.com/detail/stanford-cardinal-theme/lggkganfekdhjflflobodkbifombboji), built with official Tufts brand colors and the Jumbo elephant mark.

## Install (unpacked)

1. `chrome://extensions`
2. Enable "Developer mode"
3. "Load unpacked" → select this folder

## Assets

- Logo and Jumbo elephant mark: sourced directly from `brand.tufts.edu` (University Logo and Jumbo Athletics guideline pages).
- Colors: official Tufts palette from [brand.tufts.edu/guidelines/color](https://brand.tufts.edu/guidelines/color) — Tufts Blue `#3E8EDE`, Jumbo Blue `#002E6D`, Tufts Brown `#63493A`, Candle White `#F2EDE7`, Beacon Yellow `#FFC72C`.
